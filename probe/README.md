# Probe

Проба — отдельное приложение, которое регистрируется на сервере по токену и
получает задания через WebSocket. По каждому заданию настраивает локальный
xray-клиент и замеряет скорость через соединение.

```sh
cd probe
uv sync
uv run xspeed-probe
```

## Переменные окружения (`.env.example`)

| Имя                 | Описание                                              |
|---------------------|-------------------------------------------------------|
| `PROBE_TOKEN`       | Токен для регистрации на сервере (обязателен)          |
| `SERVER_WS_URL`     | `ws://<host>:<port>/ws/probe`                         |
| `ALIAS`             | Человекочитаемое имя пробы                            |
| `REGION_ID`         | ID региона (опционально)                              |
| `NETWORK_INTERFACE` | Исходящий интерфейс; если недоступен — задача пропускается |
